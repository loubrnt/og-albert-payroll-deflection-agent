# KB-109 — Change the pay calendar

*Help center (synthetic article for the course). Last reviewed: 2026-10-20.*

## Edit the pay calendar
Go to Settings, then Pay calendar. Click the month you want to change and edit the cutoff date for variable pay elements. Changes apply to future months only.

## Who can change it
Only Admin users can edit the pay calendar. Payroll managers see it but cannot modify it.
