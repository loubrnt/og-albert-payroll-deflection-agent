# KB-105 — Generate the bank payment file

*Help center (synthetic article for the course). Last reviewed: 2026-10-20.*

## Create the SEPA file
After the payroll run is closed, open Payroll, click Payments, then Generate SEPA file. Download the XML file and upload it in your bank portal.

## Check the bank details first
Before generating the file, open People and filter on Missing bank details. Employees with a missing IBAN are listed and are left out of the file until completed.
